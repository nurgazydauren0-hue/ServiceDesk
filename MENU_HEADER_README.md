# MovieList: одна кнопка меню и заголовок текущего раздела

Обновление для версии MovieList, в которой уже установлены обложки по жанрам и выдвижная панель.
Это не полный проект. Исходный README.md, техническое задание и package.json не заменяются.

## Изменения

- Удалён отдельный крестик рядом с логотипом MovieList.
- В верхней панели осталась одна кнопка размером 36 × 36 px.
- На кнопке нет текста «Скрыть / Меню»: только иконка. Подсказка при наведении и название для экранного диктора сохранены.
- При открытом меню кнопка скрывает его, при закрытом — раскрывает.
- Убрана строка «Моё пространство / ...».
- Вместо неё отображаются иконка и название активного раздела: «Моя коллекция», «Хочу посмотреть», «Смотрю сейчас» или «Просмотрено».
- Название в шапке и заголовок списка используют одно и то же состояние выбранного раздела.
- На мобильном экране панель открывается под шапкой. Единственная кнопка меню остаётся доступной.
- Сохранены закрытие мобильной панели по Esc, клику вне панели и выбору раздела, а также запоминание свёрнутого состояния на компьютере.

## Какие файлы заменить

app/genre-sidebar.css
components/sidebar-controls.jsx
components/movie-library.jsx

Все три файла необходимо заменить вместе. app/layout.jsx уже подключает genre-sidebar.css и менять его не нужно.
Папку data, файлы SQLite, обложки, app/globals.css, backend, package.json и Git-историю обновление не затрагивает.

## Установка в Windows

1. В терминале с работающим сайтом нажми Ctrl+C.
2. Сохрани резервные копии трёх перечисленных файлов в отдельную папку вне проекта.
3. Распакуй этот архив.
4. Скопируй папки app и components из архива в ту же папку movielist, из которой запускаешь сайт: рядом с package.json.
5. Подтверди замену совпадающих файлов. Не удаляй существующие папки целиком.
6. Открой терминал в папке проекта и запусти:

```powershell
& "C:\Program Files\nodejs\npm.cmd" run dev
```

7. Открой адрес Local, который напечатал сервер, и обнови страницу через Ctrl+F5.

Повторная установка зависимостей и повторная загрузка обложек не нужны.
Если путь установки Node.js отличается, используй свой путь к npm.cmd.

## Проверка после установки

У логотипа больше нет крестика. Сверху есть только одна компактная кнопка управления панелью.
Нажми её дважды: панель должна скрыться и снова раскрыться.
Выбери по очереди четыре раздела слева: название сверху и заголовок списка должны соответствовать выбранному разделу.
На узком экране эта же кнопка должна закрывать открытое меню; Esc и клик по затемнённой области тоже должны работать.

## Что проверено при подготовке

- Синтаксис обоих JSX-файлов и разбор CSS.
- 15 изолированных проверок компонентов и логики: одна кнопка без видимого текста, доступное имя, все четыре заголовка, переключение меню, состояние на сервере, Esc, клавиатурный переход и возврат фокуса.
- Вёрстка в Chromium на ширинах 1440, 958, 390 и 320 px: размер кнопки, отсутствие горизонтального переполнения, размещение названий и доступность кнопки поверх мобильной панели.
- Блок стилей обложек совпадает с предыдущим обновлением.

Ограничение проверки: изолированные проверки использовали тестовую подстановку React-хуков, а браузерная проверка — статическую разметку из JSX с настоящими CSS. Полная сборка и запуск Next.js с backend в этой среде не выполнялись: пакеты проекта недоступны для установки. После копирования проверь результат в своём работающем приложении.

## Справка для разработчика

Обновление не добавляет библиотек. У кнопки сохранены aria-controls и aria-expanded; подпись задана через aria-label/title.
Боковая панель оформлена как обычная раскрываемая навигация, а не как ARIA-menu.
Документация: https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/

# MovieList — обложки по жанру и выдвижная панель

Это обновление существующего MovieList, не отдельный проект.
Подготовлено для исходного проекта из movielist-project.zip с уже установленной
сине-фиолетовой темой. globals.css, backend, база, package.json и Git не заменяются.

## Установка в Windows

1. Останови запущенный сервер в терминале VS Code: Ctrl+C.
2. Сохрани резервные копии четырёх заменяемых файлов:
   - app/layout.jsx
   - components/movie-card.jsx
   - components/movie-form.jsx
   - components/movie-library.jsx
3. Распакуй этот архив. Скопируй его папки app, components, lib, scripts, tests и docs
   ВНУТРЬ папки проекта movielist — туда, где находится package.json.
   По предыдущему скриншоту это:
   C:\Users\Lenovo\Desktop\movielist-project\movielist
4. Подтверди замену совпадающих файлов. Папки объединяются: существующие папки
   app, lib и components УДАЛЯТЬ НЕ НУЖНО.
5. В терминале в папке проекта запусти:

```powershell
npm.cmd run dev
```

6. Обнови открытую страницу MovieList сочетанием Ctrl+F5.

Повторно устанавливать библиотеки через npm ci не требуется.
Не удаляй data/movielist.sqlite: там хранится твоя коллекция.
В этом архиве нет базы и нет .git: сохранённые фильмы и история Git не заменяются.

## Как выбирается изображение

Фильм уже содержит поле genre. На его основе интерфейс выбирает одну фотографию:

- Фантастика → космонавт.
- Драма → кинематографичный портрет у окна.
- Комедия → смеющиеся друзья.
- Триллер → туманная ночная улица.
- Боевик → два человека в тактическом снаряжении на фоне дыма.
- Мультфильм → яркая мультяшная фигурка.
- Другое → кинозал.

Это шесть основных жанров и дополнительное «Другое» из существующей формы.
У всех фильмов одного жанра одна и та же фотография. Название, ID, год, оценка и
статус не влияют на выбор изображения. Это тематические фотографии жанров,
а не официальные постеры конкретных фильмов.

Новые и старые записи используют эту логику одинаково. Не нужно пересоздавать
фильмы, менять базу или вводить ссылку. При редактировании жанра обложка меняется.
В форме есть предварительный просмотр, а поля для ссылки нет.

## Интернет и локальные фотографии

В архиве находится код с заранее выбранными источниками фотографий, а не сами
фотографии. По умолчанию браузер получает их с Pexels и Unsplash. Для этого нужен
интернет и доступ к этим сайтам. API-ключи и регистрация не нужны.
Если изображение не загрузится, карточка сохранит название, жанр и все кнопки,
а вместо сломанного изображения будет показана понятная заглушка.

Для работы с локальными фотографиями один раз, при доступном интернете, выполни
в папке movielist (при остановленном сервере или в отдельном терминале):

```powershell
node scripts/download-genre-posters.mjs
```

Команда автоматически скачивает выбранные фотографии в public/genres и записывает
настройку в lib/local-genre-images.js. После сообщения «Локальных обложек: 7 из 7»
эти фотографии больше не требуют доступа к внешним сайтам. Неудачные загрузки
не удаляют уже сохранённые фотографии; команду можно повторить. Нескачанные
жанры продолжают использовать онлайн-источники.

У шрифта Manrope остаётся прежняя внешняя загрузка из globals.css; без интернета
используется предусмотренный в исходной теме системный шрифт.

## Боковая панель

- На компьютере кнопка «Скрыть / Меню» находится вверху слева.
- При скрытии панель уезжает влево, а содержимое расширяется.
- Настройка на компьютере запоминается в localStorage этого браузера.
- На экране шириной 820 px и меньше меню по умолчанию скрыто и открывается поверх
  страницы. Закрывается крестиком, нажатием на затемнение или Escape.
- После выбора раздела на узком экране меню автоматически закрывается.
- В скрытое меню нельзя попасть клавишей Tab; в мобильном открытом меню фокус
  удерживается внутри. Кнопки снабжены aria-label и aria-expanded.

## Быстрая проверка у себя

1. Открой два старых фильма одного жанра: фон должен совпадать.
2. Добавь два разных боевика: у них должна быть одинаковая фотография.
3. Измени один из них на комедию: появится картинка комедии.
4. Убедись, что название, оценка, удаление, фильтры и сохранение работают как прежде.
5. Нажми «Скрыть», затем «Меню». Перезагрузи страницу и проверь сохранение положения.
6. Сузь окно: открой меню, закрой крестиком, затем проверь Escape и клик по затемнению.

```powershell
node --test tests/genre-posters.test.mjs
```

```powershell
npm.cmd run build
npm.cmd test
```

Проверки нового модуля обложек не требуют запущенного сервера.
Полный статус выполненных проверок указан в docs/UPDATE_CHECKS.md.

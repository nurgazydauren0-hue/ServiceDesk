# MovieList — новая навигация и отдельное добавление фильма

## Что изменено

1. «Добавить фильм» — отдельный пункт в левой панели. Он открывает полноценную форму внутри сайта, а не всплывающее окно. Адрес страницы не меняется.
2. В главном баннере теперь текст:
   «Больше хорошего кино.
   Сохраняй то, что хочется посмотреть. Возвращайся к тому, что запомнилось.»
   Крупная кнопка добавления из баннера убрана. Декоративные билеты и текущая палитра сохранены.
3. Дублирующий текст слева, псевдоаватар, надпись «Твоя фильмотека» и декоративный онлайн-индикатор удалены.
4. «О MovieList» перенесено в правую часть верхней панели. Текст информационного окна сохранён. На телефоне кнопка компактная, с иконкой информации.
5. «К моей коллекции» в информационном окне действительно возвращает к общему списку, а не просто закрывает окно.
6. Сохранены предыдущие улучшения: одна кнопка меню 36×36 без лишнего крестика; название текущего раздела вместо «Моё пространство / …».
7. Плавающий значок Next.js «N» отключён через devIndicators: false. Сообщения об ошибках разработки НЕ отключены.
8. Неотправленный черновик формы сохраняется при переключении разделов до успешного добавления или перезагрузки страницы. После добавления открывается общая коллекция, новая запись видна, форма очищается. При ошибке данные остаются в форме.
9. Редактирование существующего фильма по-прежнему открывается в диалоге. Поиск, фильтры, статусы, оценки и обложки по жанрам сохранены.

## Установка

Это дополнение к твоему MovieList, в котором уже установлено обновление «обложки по жанрам + выдвижная панель».
Предыдущий отдельный архив с компактной кнопкой меню устанавливать не обязательно: его изменения включены сюда.

1. В терминале работающего сайта нажми Ctrl+C.
2. Сохрани копии пяти файлов, перечисленных ниже, в отдельной резервной папке вне проекта.
3. Распакуй архив. Скопируй папки app, components и docs, а также файл next.config.mjs В КОРЕНЬ ЗАПУСКАЕМОГО ПРОЕКТА — рядом с package.json.
   Текущий путь из нашей переписки: C:\Users\user\Desktop\movielist.
4. Подтверди замену совпадающих файлов. НЕ удаляй папки app или components целиком — объединяй содержимое.
5. Все пять рабочих файлов нужно обновить вместе:

```text
app/genre-sidebar.css
components/movie-library.jsx
components/movie-form.jsx
components/sidebar-controls.jsx
next.config.mjs
```

Если ты самостоятельно добавлял настройки в next.config.mjs, сохрани их и добавь внутрь объекта nextConfig строку `devIndicators: false,` вместо замены всего файла.

6. В PowerShell из папки проекта запусти:

```powershell
& "C:\Program Files\nodejs\npm.cmd" run dev
```

7. После сообщения Ready открой адрес Local из терминала и нажми Ctrl+F5. Перезапуск сервера нужен в том числе для next.config.mjs.

Повторная установка npm-зависимостей и загрузка фотографий НЕ нужны.
Этот архив не содержит и не заменяет data/, public/genres/, lib/local-genre-images.js, globals.css, package.json, package-lock.json или Git-историю.

## Проверка после установки

- Внизу боковой панели больше нет аватара и «Твоя фильмотека».
- Возле логотипа нет крестика. Кнопка раскрытия/скрытия — одна, квадратная, в шапке.
- На главной новый текст, в баннере нет кнопки добавления.
- «О MovieList» находится сверху справа; содержимое окна осталось прежним.
- Нажми «Добавить фильм» слева: откроется форма, а заголовок сверху изменится на «Добавить фильм».
- Заполни название, перейди в «Моя коллекция», вернись к форме: название должно остаться.
- Добавь фильм: откроется общий список с новой записью.
- Измени или удали тестовую запись. Проверь обложку по жанру.
- На телефоне меню открывается и закрывается той же кнопкой; Esc и затемнённая область также закрывают его.

# Проверки обновления

## Выполнено

- 7 автоматических тестов выбора обложек: пройдены.
- Проверены соответствие всем жанрам, одинаковые фото для одного жанра,
  изменение обложки при смене жанра, независимость от названия,
  неизвестные значения, источники HTTPS и неизменность общего каталога.
- Все 8 JSX-файлов проверочной копии успешно преобразованы TypeScript transpileModule;
  сгенерированный JavaScript прошёл node --check.
- Проверен синтаксис JS/MJS, существование локальных импортов и разбор CSS через PostCSS.
- Статическая HTML-разметка, полученная из компонентов с тестовыми данными,
  проверена в Chromium на ширинах 1440, 958, 390 и 320 px. При открытой и закрытой
  панели горизонтального переполнения страницы нет; при скрытии на компьютере
  левый отступ основного содержимого становится нулевым.
- Проверено побайтово: backend, модуль SQLite, валидация, список жанров,
  package.json, package-lock.json и ранее подготовленный globals.css не изменены.

## Не проверено здесь

Полная сборка и запуск в Next.js, интерактивные сценарии в настоящем React,
а также загрузка всех фотографий из браузера: окружение не смогло подключиться
к внешним серверам для установки зависимостей и загрузки изображений.
Статическая проверка вёрстки не подменяет сквозное тестирование приложения.

После копирования обновления выполните ручную проверку из UPDATE_README.md.
Существующие тесты API не изменены; их можно запустить после npm run build.

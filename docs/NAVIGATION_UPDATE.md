# Обновление навигации MovieList

## Технические изменения

- MovieLibrary хранит выбранный вид: collection или add. Это внутренняя навигация одного приложения, не отдельный URL-маршрут.
- MovieForm получает presentation="page" для добавления; стандартное значение "dialog" сохраняет модальное редактирование.
- Форма добавления остаётся смонтированной при переключениях, но скрывается нативным hidden. После успешного POST ключ формы меняется, сбрасывая черновик.
- Пока выполняется сохранение, поля и выход из формы через навигацию блокируются. При неудаче форма разблокируется, сообщение об ошибке и введённые значения сохраняются.
- Текст верхнего заголовка определяется выбранным разделом. У активного пункта навигации aria-current="page".
- Профиль и ссылка о проекте удалены из aside; ссылка о проекте перенесена в header. Диалог использует прежний текст.
- Кнопка меню сохраняет aria-expanded, aria-controls, подсказку и компактный размер.
- Для телефона сохранены управление клавиатурой, закрытие по Esc, ограничение фокуса открытым меню и возврат фокуса к кнопке.
- next.config.mjs: только добавлено devIndicators: false, poweredByHeader: false сохранено.
- Серверные маршруты, SQL, жанры и сохранённые фотографии не менялись.

## Что фактически проверено

1. TypeScript transpileModule: синтаксис всех JS/JSX/MJS файлов проекта — без ошибок. Это не заменяет next build.
2. Семь существующих тестов выбора обложек по жанрам — прошли.
3. Семь сценариев оригинальных API-обработчиков при прямом вызове под Node.js 22.16.0 с отдельной временной SQLite: чтение, создание с полями формы, фильтрация, изменение, повторное открытие базы, отклонение некорректных данных, удаление — прошли. Это не проверка HTTP-сервера Next.js.
4. 24 проверки интерфейса в Chromium: исходные JSX-компоненты преобразованы только для изолированного теста и отрисованы доступным локально React 18.2. Использован тестовый API в памяти. Нативный HTML-атрибут inert адаптирован в тестовом рендерере к React 18. Исходники проекта под React 19 не заменялись.
5. Визуально просмотрены главная и форма добавления на компьютере, главная на телефоне. Горизонтальное переполнение проверено на ширинах 958, 590, 390 и 320 px, также исходный экран — 1440 px.

### Проверки интерфейса

- Начальная коллекция отображается (изолированные тестовые данные)
- Нет аватара, псевдопрофиля, лишнего крестика и старого блока слева
- В баннере только новый текст, нет кнопки добавления
- Одна кнопка меню 36×36
- Меню скрывается и раскрывается
- Заголовок меняется вместе с разделом
- Добавление — отдельный раздел, не диалог
- Черновик и выбранный жанр сохраняются при смене раздела
- О MovieList открывается из шапки, текст сохранён
- К моей коллекции действительно возвращает в коллекцию
- Форма отправляет запрос создания (тестовый API)
- После сохранения открыт общий список с новым фильмом
- Редактирование через диалог работает
- Удаление через диалог работает
- При ошибке форма сохраняет черновик и снова доступна
- Нет горизонтального переполнения главной на 958px
- Форма помещается на 958px
- Нет горизонтального переполнения главной на 590px
- Форма помещается на 590px
- Нет горизонтального переполнения главной на 390px
- Форма помещается на 390px
- Нет горизонтального переполнения главной на 320px
- Форма помещается на 320px
- Ошибок JavaScript нет

## Чего эти проверки не подтверждают

Полная сборка Next.js 16.4.2 + React 19.3.1 + Node.js 24 не запускалась: зависимости проекта недоступны для установки в рабочей среде. SSR/hydration и сквозной браузерный тест с сервером Next.js не проверены. Внешние фотографии и Google Fonts в изолированном предпросмотре не загружались; отображался штатный резервный вид и системный шрифт. Код загрузки фотографий и основной файл оформления не менялись.

После применения проверь `npm.cmd run dev` и обычный сценарий создания/редактирования/удаления на своей машине.
